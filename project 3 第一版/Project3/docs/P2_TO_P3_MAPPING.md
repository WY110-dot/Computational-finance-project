## 2. 为什么需要明确区分 A 与 A0？

在 Project 2 中，$A_0 = \text{sign}(m_{12})$ 属于离散三值信号（$-1, 0, +1$）。在非负（Long/Cash）投资约束下，符号信号等价于二值过滤（$+1$ 持有，$-1$ 或 $0$ 空仓）。
然而，在截面多资产选券研究中：
1. **US9 截面过小（仅 9 只 ETF）**：在牛市或普涨月份，所有 9 只 ETF 的 12M 动量可能全为正（全部为 $+1$），导致截面标准差为 0，Rank IC 与分组排序完全退化。
2. **信息粒度不同**：符号信号丢弃了动量幅度大小的全部信息。若直接以 $A_0$ 作为唯一截面选券基准，无法公平检验连续微观效率因子是否提供了增量信息。
3. **严格对照**：因此，本研究遵照老师指南第 5 页，将经典连续 12M 动量 $A = z_{\text{cs}}(\text{winsor}(m_{12}))$ 作为公平比较的基准 A，同时将 P2 原始符号信号 $A_0$ 作为追溯对照，分别列入主表与辅助表。

## 3. 本次新增因子的本质贡献

- **不是**参数微调（如 20 天改成 21 天）；
- **不是**重复 P2 的多期限等权平均（3/6/12M）；
- **而是**：在经典 12M 累计动量宏观趋势的基础上，引入了微观日频交易路径的“效率比率（Efficiency Ratio, ER）”非线性乘性交互，测试市场在消化趋势过程中的路径平滑度是否能有效滤除动量噪声。
