## 2. Project 3 核心工作与责任划分

1. **研究假设与因子卡设计**：
   - 提出“12M动量 × 趋势路径效率”交互模型，设计主因子 F1、变体 F2 与反向机制对照 F3。
   - 制定前置假设卡、因子卡、时点切分规范及否定条件。
2. **算法开发与平台接入**：
   - 开发 `quantcf.project3_factors`：实现连续动量、路径效率比率（ER）算法、极值与平价路径防御、截面 Winsorization 与 Z-Score。
   - 开发 `quantcf.project3_pipeline`：实现严格的时间划分过滤、月度 Open-to-Open 前向预测标签、分位数分组及逆波动率加权。
   - 接入 P1 Broker 账本：生成完整 orders、fills、holdings、ledger 记录，执行 0/3/10 bps 费用情景回测与资金审计。
3. **统计严谨性与增量检验**：
   - 实现日频与月末截面相关性检验。
   - 实施残差因子回归检验（$B = \alpha_t + \beta_t A + \epsilon_t$）。
   - 实施自主扩展：成对循环移动分块 Bootstrap（Circular Block Bootstrap，3/6/12 个月块长，2000 次重采样），输出 95% 置信区间。
4. **验证、冻结与报告**：
   - 建立机器可读冻结文件 `outputs/freeze_manifest.json` 与验收矩阵 `outputs/acceptance_matrix.csv`。
   - 实现端到端自动化重跑验证 `verify_project3.py --rerun`，确保数值无漂移。
   - 自动生成同源中文 Markdown 与 PDF 综合研究报告。
