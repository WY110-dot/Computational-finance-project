## 1. 核心研究问题

**新因子是否在 P2 方法（时间序列动量/经典动量基准）之外提供增量预测与投资组合信息？**

在 Project 2 中，我们复现了 Moskowitz, Ooi & Pedersen (2012) 的时间序列动量（TSMOM）方法，发现其在 ETF 替代样本（CN21、US9）中的离散符号信号存在截面退化、多头胜率受限及对融资成本敏感等局限。Project 3 旨在探索：**在经典的 12 个月价格动量基础上，引入微观日频价格运行的“路径效率”交互信息，能否有效过滤噪声震荡，提供增量 Alpha？**

---

## 2. 待检验机制与预期方向

### 2.1 经济/统计机制假设
- **动量异质性假设**：两只资产在过去 12 个月内即使录得完全相同的累计收益率 $m_{12}$，其内部价格路径也可能迥异：
  - **高效趋势路径（Smooth/Efficient Trend）**：价格呈现持续、平稳、单向推升，日度波动方向高度一致，表明市场信息被逐步且有序地消化，趋势具有较强的惯性与延续概率。
  - **低效噪声路径（Noisy/Volatile Path）**：价格经历剧烈往返拉锯、宽幅震荡或单日跳空后横盘，表明市场多空分歧剧烈，未来均值回归或反转风险增加。
- **效率比率指标 (Efficiency Ratio, ER)**：采用 Perry Kaufman 的价格路径效率定义，以过去 $L$ 个交易日对数收益率的净位移绝对值除以日度收益率绝对值之和：
  $$ER_L(i,t) = \frac{\left|\sum_{d=1}^L r_{\log}(i,d)\right|}{\sum_{d=1}^L |r_{\log}(i,d)|} \in [0, 1]$$
- **新因子交互设计**：将 12 个月累计动量原始分数 $b(i,t) = m_{12}(i,t)$ 与路径效率 $ER_L(i,t)$ 相乘：
  $$F_1(i,t) = b(i,t) \times ER_{63}(i,t)$$
  高效平稳上升的动量资产被赋予更高权重，而高波噪声型资产被向下惩罚。

### 2.2 预期预测方向
- **正向预测关系**：新因子分数越高，预期下一月度持有期的收益率越高。
- **组合改善**：将标准化新因子 $B$ 与经典动量基准 $A$ 等权合成策略 $C = z_{\text{cs}}(0.5A + 0.5B)$，预期在保持同等换手与费用下，展现优于单一动量基准 $A$ 的收益风险比。

## 3. 相对 P2 基准的新增贡献

1. **信息维度扩展**：从单一的月末宏观低频收益（12M），深入到日度微观交易维度的路径质量交互（Trailing 63-day ER）。
2. **非冗余交互结构**：不仅考察动量大小，而且利用路径效率作为可变置信度权重（Confidence Weighting），与动量形成乘性交互。
3. **基准严谨界定**：
   - $A_0$：P2 原始离散符号信号 $\text{sign}(m_{12})$（保留作为追溯基准）。
   - $A$：老师允许的“相关经典因子”连续 12M 动量截面标准化分数 $z_{\text{cs}}(\text{winsor}(m_{12}))$。
   - $B$：新因子 $z_{\text{cs}}(\text{winsor}(F_1))$。
   - $C$：基准与新因子的等权标准化合成组合。

---

## 4. 预设否定与削弱条件 (Falsification Criteria)

只要出现以下情形之一，即认定假设受到严重质疑或被否定：
1. **预测性失效**：在严格隔离的评估区间（Evaluation Split）中，$F_1$ 的月度 Rank IC 均值不显著为正（$t < 1.65$ 或均值 $\le 0$）。
2. **增量冗余**：在截面回归 $B = \alpha_t + \beta_t A + \epsilon_t$ 中，残差因子 $\epsilon_t$ 对未来收益率的 Rank IC 均值接近于 0 或为负，表明新因子的预测力已被经典动量完全解释。
3. **组合未增量 ($C - A \le 0$)**：在 3 bps 基础费用及 99% NAV 真实账本约束下，组合 $C$ 相对基准 $A$ 的年化超额收益 $\Delta \text{AnnReturn}$ 跨越 0，或配对 Block Bootstrap 95% 置信区间包含 0。
4. **反向机制反例同样好或更好**：反向机制对照因子 $F_3 = b \times (1 - ER_{63})$（强调噪声路径）如果录得与 $F_1$ 相当或更好的超额表现，则证伪“路径平滑促进动量延续”的原机制假说。
5. **脆弱性与成本侵蚀**：在 10 bps 高成本情景下，微弱优势被交易成本彻底吞噬；或收益完全集中于单一年份/单个月份（时间子区间不稳定）。

## 5. 对照基准与候选设计

- **主因子 (F1)**：$b \times ER_{63}$（主假设）。
- **有目的窗口变体 (F2)**：$b \times ER_{126}$（检验中期约半年路径效率是否具有相似效应）。
- **反向机制对照 (F3)**：$b \times (1 - ER_{63})$（反例检验）。
- **基准 (A)**：连续 12M 动量标准化分数。
- **追溯基准 (A0)**：P2 原始离散符号信号 $\text{sign}(m_{12})$。
- **合成组合 (C)**：$z_{\text{cs}}(0.5A + 0.5B)$。
