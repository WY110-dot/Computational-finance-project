## 1. 资产池与数据环境

本研究在两个独立的资产池上分别进行检验，两市场完全隔离，不混用货币、交易日历或截面分位数：
1. **CN21 资产池**：21 只中国境内主流宽基、行业、主题与海外跨境 ETF，日频数据来源于 Tushare 官方复权快照，区间覆盖 2019-01-02 至 2026-09-18。
2. **US9 资产池**：9 只美国标普行业精选 SPDR ETF（XLB, XLE, XLF, XLI, XLK, XLP, XLU, XLV, XLY），日频 OHLC 调整价格快照，区间覆盖 1998-12-22 至 2026-02-06。

## 2. 时间划分、纪律与历史查看说明

### 2.1 必须如实披露的历史查看
在 Project 2 中，团队已经对现有历史行情进行了回顾性研究。因此，本轮 Project 3 满足**“样本外评估区间严格不参与新因子探索与筛选（Out-of-Sample from Research Tuning）”**，但**不声称这些数据从未被人类或既有模型查看过**。研究协议区分三个层次：
1. **已有数据上的新因子时间隔离评估**：本次 Project 3 的正式评估区间。
2. **绝对未见数据（True Out-of-Sample）**：未来新增截面或后续年份数据。
3. **P5 保留区间（P5 Quarantined Split）**：为后续终期项目保留，本轮 Project 3 坚决物理隔离，不读取、不运算、不生成因子与绩效图表。

### 2.2 确定的时间划分方案
时间划分以完整的持有期交易标签 `[entry_date, exit_date]` 为准（`entry_date >= split_start` 且 `exit_date <= split_end`）：

| 市场 | 开发区间 (Develop) | 验证区间 (Validate) | 本轮 P3 评估区间 (Evaluate) | 从 P3 起严格隔离的 P5 区间 |
| :--- | :--- | :--- | :--- | :--- |
| **US9** | 2000-01-01 ～ 2014-12-31 | 2015-01-01 ～ 2019-12-31 | **2020-01-01 ～ 2024-12-31** | 2025-01-01 之后（当前快照无该段，标记待未来数据） |
| **CN21** | 2020-02-01 ～ 2021-12-31 | 2022-01-01 ～ 2022-12-31 | **2023-01-01 ～ 2024-12-31** | 2025-01-01 ～ 2026-08-31（快照已存在，物理隔离不读入） |

- **共同双市场比较区间**：仅限于两者同时可用的 **2023-01-01 至 2024-12-31**（共约 24 个月）。不得把 US9 较早的 2020-2022 年数据伪装为双市场共同增量。
- **暖机（Warmup）规则**：形成日前的数据可用于暖机（至少 13 个历史月末和至少 252 个连续日度收益率）；历史暖机不属于未来信息泄漏。跨越分区边界的交易标签被拒绝；进入 P5 的交易标签被完全剔除。

## 3. 组合构建与执行规则（公平 A/B/C）

主对照实验在 A、B、C 方案之间保持资产、标签、调仓日、价格口径、权重规则与成本的绝对公平一致：

1. **基准与方案定义**：
   - **A (Baseline)**：经典连续 12M 动量标准化分数 $A$。
   - **B (New Factor)**：主新因子 $B = z_{\text{cs}}(\text{winsor}(F_1))$。
   - **C (Combo)**：等权标准化合成组合 $C = z_{\text{cs}}(0.5 A + 0.5 B)$。
   - **辅助方案**：$A_0$（P2 符号信号）、$F_2$（126日变体）、$F_3$（反向机制对照）、等权被动多头、逆波动率被动多头。
2. **资产准入门槛**：
   - 形成日必须具备至少 13 个历史月末价格以计算 12M 动量。
   - 必须具备至少连续 252 个有效日度收益率以估计 EWMA 波动率。
   - 当日共同合格资产总数必须 $\ge 6$（沿用 P2 门槛）。
3. **选券分组与并列处理**：
   - 截面按得分排序分为三组（Bottom T1, Middle T2, Top T3），每组目标质量为 $N / 3$。
   - 投资组合仅做多最高组（Top Tercile, T3），不做空，不融资。
   - 若得分出现并列，采用分位数质量分摊法（Fractional Membership），禁止按资产代码字母顺序随机指定胜出者。
4. **资金分配与风险平价**：
   - 入选资产根据形成日截至当日的 EWMA 年化波动率 $\sigma_i$ 进行逆波动率加权：
     $$w_i \propto \frac{\text{membership}_i}{\sigma_i}$$
   - EWMA 衰减参数 $\lambda = 60/61$，历史窗口 $\ge 252$ 天，年化因子 261。
   - 总投资预算严格限制为 99% NAV，保留 1% 现金；不允许杠杆借贷。
5. **执行层 (P1 Broker)**：
   - 调仓执行：形成日月末收盘产生信号，次交易日开盘以复权开盘价执行。
   - 账本完整性：输出订单表 (orders)、成交表 (fills)、持仓表 (holdings)、现金及资产净值流水账本 (ledger)。
   - 资金约束：现金非负、持仓非负、预算严格闭合。
   - 基础费率：单边 3 bps；稳健性测试包含 0 bps 与 10 bps。

## 4. 统计与增量检验方法

1. **因子 IC 与分组单调性**：
   - 逐期 Pearson IC 与 Spearman Rank IC，报告均值、标准差、ICIR 与正比率。
   - 三组前向收益（T1, T2, T3）及多空利差（T3 - T1）。
2. **截面相关性诊断**：
   - 月末形成日截面相关性（$b$ 与 $F_1$；$A$ 与 $B$）。
   - 逐交易日日频截面相关性（涵盖所有非月末交易日）。
3. **加入/移除检验 ($C - A$)**：
   - 配对比较同一账本执行口径下组合 $C$ 与组合 $A$ 的月度净收益序列差值 $R_C(t) - R_A(t)$。
   - 报告年化超额收益、超额 Sharpe、跟踪误差与最大回撤变化。
4. **截面残差因子诊断**：
   - 在每个形成日，对共同合格资产做截面 OLS：$B_{i,t} = \alpha_t + \beta_t A_{i,t} + \epsilon_{i,t}$。
   - 对残差因子 $\epsilon_{i,t}$ 计算其对未来收益率 $y(i,t)$ 的 Rank IC 和三组前向收益，检验纯净路径效率是否具备独立选券能力。
5. **自主扩展：配对循环移动分块 Bootstrap (Circular Block Bootstrap)**：
   - 保留时间序列自相关与异方差结构，以月度日期为抽样单位，$C$ 与 $A$ 成对移动。
   - 块长（Block Size）：主块长 3 个月；敏感性测试 6 个月；长历史（US9 评估期）列出 12 个月。
   - 重复抽样 2000 次，固定随机种子 20261116。
   - 输出成对超额年化收益与成对 Sharpe 差值的 95% 百分位置信区间及胜率。
