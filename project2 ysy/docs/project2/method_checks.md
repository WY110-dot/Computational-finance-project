### 1.1 12 个月动量趋势与自身方向映射
- **输入设定**: 连续 13 个自然月末，价格从 100 变动至 110。
- **解析预期**:

  若缺少其中任意一个必要月末价格，收益率与信号判定为无效（NaN），不参与形成。
- **自身方向检验**:

- **核验状态**: **通过** (`test_momentum_direction_mapping`)。

### 1.2 有限历史指数加权方差 (EWMA) 解析核对
- **输入设定**: 衰减系数 $\lambda = 0.5$，时间序列收益率（由旧到新）为 $r = [0.01, -0.01, 0.02]$，样本数 $n = 3$。
- **手算推导步骤**:
  1. 权重指标 $j$: 最新的 $0.02$ 对应 $j=0$；中间的 $-0.01$ 对应 $j=1$；最旧的 $0.01$ 对应 $j=2$。
  2. 未归一化权重 $\lambda^j$: $0.5^0 = 1$, $0.5^1 = 0.5$, $0.5^2 = 0.25$。总和为 $1 + 0.5 + 0.25 = 1.75 = 7/4$。
  3. 归一化权重 $a_j$:
     $$a_0 = \frac{1}{7/4} = \frac{4}{7}, \quad a_1 = \frac{0.5}{7/4} = \frac{2}{7}, \quad a_2 = \frac{0.25}{7/4} = \frac{1}{7}$$
     按时间由旧到新权重向量即为 $[1/7, 2/7, 4/7]$。
  4. 加权均值:
     $$\mu = \frac{1}{7}(0.01) + \frac{2}{7}(-0.01) + \frac{4}{7}(0.02) = \frac{0.01 - 0.02 + 0.08}{7} = \frac{0.07}{7} = 0.01$$
  5. 偏离度与加权方差:
     - 旧 ($0.01$): $(0.01 - 0.01)^2 = 0$
     - 中 ($-0.01$): $(-0.01 - 0.01)^2 = (-0.02)^2 = 0.0004 = 4/10000$
     - 新 ($0.02$): $(0.02 - 0.01)^2 = (0.01)^2 = 0.0001 = 1/10000$
     $$v = \frac{1}{7}(0) + \frac{2}{7}\left(\frac{4}{10000}\right) + \frac{4}{7}\left(\frac{1}{10000}\right) = \frac{8 + 4}{70000} = \frac{12}{70000} = \frac{3}{17500} \approx 0.00017142857$$
- **核验状态**: **通过**，实际函数输出与手算值完全一致（误差 $< 10^{-16}$）。

### 1.3 论文多空理论权重与下一期收益贡献核算
- **输入设定**: 合格资产数 $N = 2$；目标年化缩放尺度 $0.40$；资产年化波动率分别为 $\sigma_1 = 0.20$, $\sigma_2 = 0.10$；动量方向分别为 $s_1 = +1$, $s_2 = -1$。
- **权重计算**:
  $$w^{TS}_1 = \frac{1}{2} (+1) \frac{0.40}{0.20} = +1.0, \qquad w^{TS}_2 = \frac{1}{2} (-1) \frac{0.40}{0.10} = -2.0$$
  被动对照组（Passive Long，所有方向置为 $+1$）:
  $$w^{PL}_1 = \frac{1}{2} (+1) \frac{0.40}{0.20} = +1.0, \qquad w^{PL}_2 = \frac{1}{2} (+1) \frac{0.40}{0.10} = +2.0$$
- **收益贡献与组合加总**:
  设下一期资产收益率分别为 $r_{1,t+1} = +5\%$, $r_{2,t+1} = -2\%$。
  - TSMOM 理论收益:
    $$R^{TS} = (+1.0)(+0.05) + (-2.0)(-0.02) = +0.05 + 0.04 = +0.09 = +9.0\%$$
  - 被动做多收益:
    $$R^{PL} = (+1.0)(+0.05) + (+2.0)(-0.02) = +0.05 - 0.04 = +0.01 = +1.0\%$$
- **核验状态**: **通过** (`test_long_short_research_weights_and_contributions`)。

### 1.4 Long/Cash 真实交易预算分配核算
- **输入设定**: 延续上例两资产，总投资比例预算 $0.99$。
  - 逆波动率: $1/\sigma_1 = 1/0.20 = 5$, $1/\sigma_2 = 1/0.10 = 10$，倒数和为 $15$。
  - 基础预算:
    $$b_1 = 0.99 \times \frac{5}{15} = 0.33, \qquad b_2 = 0.99 \times \frac{10}{15} = 0.66$$
  - 方向过滤与最终权重:
    $$w^{LC}_1 = 0.33 \times \max(+1, 0) = 0.33, \qquad w^{LC}_2 = 0.66 \times \max(-1, 0) = 0.00$$
  - 目标留存现金: $1.0 - 0.33 = 0.67$ (67%)。
- **核验状态**: **通过** (`test_long_cash_execution_budget_allocation`)。
