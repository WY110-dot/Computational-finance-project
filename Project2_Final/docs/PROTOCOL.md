# 固定研究协议与判定规则

本次整合日期：2026-10-29。研究是回顾性，不将整合时固定的设置宣称为结果查看前的预注册。作者：杨皓博、袁思扬、缪梓航。

## 目标与边界

复现 Moskowitz, Ooi & Pedersen (2012) Eq. (5)、Fig. 2 上部与 Fig. 3 的构造和比较；在 ETF 替代样本检验能否观察到相对被动多头的优势。数据不是原文期货集，故只能称方法迁移。原文 Table 2 为不同回看/持有期的 alpha t 值，不作为 Sharpe 1.01 的来源。

主基线：12M 符号、月度形成/持有、40% 单资产年化 EWMA 波动率预算、1/N；参考序列 AQR 只做指标复算。原始研究层零费用、无组合风险再缩放；执行层 next open、99% 逆波动预算、无空头借贷、3 bp 单边费用，独立 0/10 bp 费用对照。

## 固定实验

1. CN21 完整持有期 2020-02 至 2026-08，US9 2000-01 至 2024-12；共同持有期 2020-02 至 2024-12。
2. 多期限扩展为 (s3+s6+s12)/3，不优化期限或系数；逐项保留结果。
3. 风险对齐为形成日 EWMA 协方差目标 12%、gross 上限 6，之后才取下一期收益，不以全样本实现波动反向决定仓位。
4. 配对循环移动分块 bootstrap，块长 3/6/12 月各 2000 次、种子 20261029，报告百分位 95% 区间，不挑最有利块长。
5. 形成日集合由历史可得价格与波动率决定；未来缺失收益不改 N，无法观察时显式报错。
6. 融资压力测试 0/2/4/6%，扣 max(net exposure-1,0)×费率/12，不能替代完整融资与借券模型。

## 判定

“方法实现并核验”与“重现相对优势”分开。正 Sharpe 不等于显著预测能力。只有同资产/同期间/同频率/同风险预算下的对照才用于扩展判断；收益和风险均列出，统计区间包含零时不称稳定改进。
