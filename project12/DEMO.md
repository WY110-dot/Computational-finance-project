# 5分钟演示提纲

1. **目标与架构（40秒）**：展示报告第一页。解释数据、因子、权重、成交、净值和诊断的关系。此项目不以收益或IC达标作为目标。
2. **数据（40秒）**：打开`source_manifest.json`和`quality_report.json`，说明固定版本、唯一键、缺失检查、价格口径。主动说明没有独立原价和复权因子。
3. **因子与时间对齐（50秒）**：打开`src/factors.py`，解释为什么t日收盘信号不能在t日收盘成交，为什么五日标签从t+1开盘到t+6开盘。
4. **执行器（50秒）**：展示某日`momentum_weekly_trades.csv`，按成交金额重算费用，再用现金和持仓核对净值。未成交不扣费。
5. **实验结果（60秒）**：展示报告第5—7页。三个Rank IC接近零、选股策略未跑赢等权基准；月度调仓费用更低，但收益差不能全部归因于成本。
6. **拓展与验证（60秒）**：展示受限订单、目标3只但实际可能多于3只的持仓；运行`uv run --frozen python -m unittest discover -s tests -v`。说明容量无限退化测试、未来信息测试及复现误差。

## 常见提问

- **为什么不用深度学习？** P1检验研究平台正确性；小截面简单因子已经足够覆盖接口，不需要复杂模型来制造分数。
- **IC为负是否项目失败？** 不。结果如实报告，平台能发现无效假设才有研究价值；不能看到负结果就反复换窗口。
- **价格是否真正未复权？** 不是。本项目使用上游已调整价格，缺独立因子；调整后单位账本不等于原股数经纪商账本。
- **9只资产够吗？** 足够演示三分组和横截面接口，但统计力弱、波动大，不能推广到全市场。
- **毛收益减净收益是否等于手续费？** 不是，采用零费率独立重跑，会改变再投资资金和后续持仓规模。
- **为什么持仓超过3只？** 受限卖单没有完全成交，旧持仓与新目标并存。不能强行把未成交部分删掉。
- **如何新增因子？** 注册一个返回date×asset矩阵的函数并配置窗口，回测核心无需修改。
- **AI参与了什么？** 任务拆解、代码生成、测试和文档草拟。演示者应亲自运行、理解和核对，不能把自动测试等同于个人已经完成的审查。
